# mauriciopavan.vercel.app

Personal portfolio of Mauricio Pavan, Product Engineer (web and mobile).

- Next.js 15 (App Router), React 19, TypeScript
- Tailwind CSS 4
- Fonts: Bricolage Grotesque and IBM Plex Sans (self-hosted via Fontsource)

All content lives in `app/content.ts`.

```bash
npm install
npm run dev
```
